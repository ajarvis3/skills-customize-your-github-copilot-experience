
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input. You'll practice string manipulation, loops, conditionals, and random selection to create an interactive game where players guess letters to reveal a hidden word.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a complete Hangman game that allows players to guess letters and reveals the word progressively. The game should handle multiple rounds and provide clear feedback to the player.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress (_ _ _ format)
- Track incorrect guesses remaining
- End when word is guessed or attempts exhausted
- Display win/lose messages
